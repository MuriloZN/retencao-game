# Assets

Organização sugerida para os recursos visuais e sonoros:

- `characters/`: protagonista, supervisores, clientes e chefes
- `environments/`: fachada, recepção, estacionamento e cenários
- `ui/`: HUD, ícones, botões e caixas de diálogo
- `audio/`: música e efeitos sonoros

Preferir PNG com transparência para sprites e tilesets. Registrar dimensões, escala e licença/origem de cada recurso. Não adicionar fotos ou materiais internos sem autorização.
